Classification

Toggle layers. Query areas.

Selecting any shape on the map calculates its area against every enabled layer beneath it

Regional Data Breakdown

The information panel identifies the selected region and provides precise spatial area measurements while preserving the structural integrity of the original datasets.

Overlapping Spatial Analysis

The system evaluates all active layers intersecting the selected feature such as climate or erosion, data-mapping them precisely where native data exists without filling data gaps.

Source Categorization

All classification labels and visual configurations reflect the native source datasets. The platform preserves original agency naming conventions and visual scales entirely.

Disclaimer: Area is the only computed metric. All secondary data attributes, labels, and color scales map directly from the source material. Dataset accuracy rests solely with the underlying Cadastre and NAMRIA records.
